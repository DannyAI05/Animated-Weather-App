## 📌 About the Project

The Animated Weather App is a web-based application designed to provide users with real-time weather information for different cities.

The application allows users to search for a city and view its current temperature, humidity, wind speed, and weather conditions. It also features dynamic background themes that change according to the weather, creating a more engaging and visually appealing experience.

This project was developed as a practical exercise in front-end web development, API integration, and interactive user interface design.

## ✨ Features

- 🔍 Search for weather information by city name.
- 🌡️ Display current temperature in Celsius.
- 💧 Show humidity levels.
- 🌬️ Display wind speed.
- 🌤️ Show weather condition icons.
- 🎨 Dynamic background themes based on weather conditions.
- 🌧️ Weather-specific visual themes for sunny, cloudy, rainy, and snowy conditions.
- ⚠️ Handle invalid city searches.
- ✨ Smooth visual transitions and animated effects.

## 🌍 Weather Data

The application uses the OpenWeather API to retrieve current weather information.

The API provides:

- City name
- Temperature
- Humidity
- Wind speed
- Weather conditions
- Weather icons

Weather conditions are used to determine the application's visual theme.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You need:

- A modern web browser.
- A code editor such as Visual Studio Code.
- An OpenWeather API key.

### 1. Clone the repository

```bash
git clone https://github.com/DannyAI05/Animated-Weather-App.git
```

### 2. Navigate to the project folder

```bash
cd Animated-Weather-App
```

### 3. Configure the API key

Open `script.js` and configure your OpenWeather API key.

```javascript
const apiKey = "YOUR_OPENWEATHER_API_KEY";
```

Replace the placeholder with your own API key.

You can obtain an API key from [OpenWeather](https://openweathermap.org/api).

### 4. Run the application

Open the HTML file in your browser:

`My Personal Weather app.html`

You can also open the project in Visual Studio Code and use the Live Server extension.
